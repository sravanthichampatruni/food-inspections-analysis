# Raw data

The raw file is large, so it is not stored in GitHub.

## Download
1. Go to the City of Chicago Data Portal: https://data.cityofchicago.org
2. Search for **Food Inspections**.
3. Click **Export**, choose **CSV**, and download.
4. Save the file in this folder as `food_inspections.csv`.

## Columns to expect (verify after download)
Inspection ID, DBA Name, AKA Name, License #, Facility Type, Risk, Address, City, State, Zip,
Inspection Date, Inspection Type, Results, Violations, Latitude, Longitude, Location

Note the date you downloaded the data in your README, since the portal updates regularly.
